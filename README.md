# bakery-shop-web Website

A single-page, mobile-first, fast-loading local business website.

## Features
- One-page structure
- Mobile-responsive design
- SEO-friendly meta tags
- Product and gallery sections
- Embedded Google Maps location
- Floating WhatsApp contact button
- Clean, maintainable HTML/CSS/JS

## Project Structure
```text
CakeZone/
├─ index.html
├─ css/
│  ├─ bootstrap.min.css
│  └─ style.css
├─ js/
│  └─ main.js
├─ img/
├─ AGENTS.md
└─ PLAN.md
```

## Run Locally
### With WebStorm
1. Open the project in WebStorm.
2. Open `index.html`.
3. Create a **JavaScript Debug** run configuration.
4. Example URL:
   - `http://localhost:63342/CakeZone/index.html`
5. Click **Run**.

### Open Directly
- You can also open `index.html` directly in a browser.

## Customization
- Update content: `index.html`
- Update colors, typography, and layout: `css/style.css`
- Update interactions: `js/main.js`
- WhatsApp number:
  - `https://wa.me/905397492173`

## SEO Notes
- `lang="tr"` is enabled for Turkish website content.
- `title`, `description`, `keywords`, and Open Graph tags are included.
- Non-critical images use `loading="lazy"`.
